# B站动态分组过滤

一个用于 Bilibili 动态页的 Tampermonkey 用户脚本。可以按关注分组筛选动态，也可以把多个关注分组合并为自定义标签。

## 功能

- 在 `https://t.bilibili.com/` 的原生动态分类栏旁显示关注分组标签。
- 支持多个关注分组合并为一个自定义标签，例如“画师和游戏”“科普和测评”。
- 自动提供“其余分组”：默认分组、未配置分组和以后新增的分组会自动归入其中。
- 支持添加、删除、重命名、排序和重新分配组合标签。
- 组合内用户自动去重；切换时保留 Bilibili 原生的“全部 / 视频投稿 / 追番追剧 / 专栏”分类。
- 适配 Bilibili Evolved 夜间模式及主题色，配置界面也跟随主题。
- 成员列表使用短期缓存和受限并发加载，减少重复等待；动态响应短期复用。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 通过 [GitHub](https://github.com/dust-iny/bilibili-dynamic-group-filter/raw/main/bilibili-timeline-filter-evolved.user.js) 安装。
3. 如果以前安装过原版或旧版，请停用旧脚本，只保留本脚本启用。
4. 打开或刷新 <https://t.bilibili.com/>。脚本需要在登录状态下使用。

## 默认组合

首次运行时不再依赖固定的“画师”“游戏”等示例名称，而是读取账号当前可用关注分组的顺序：

| 标签 | 包含内容 |
| --- | --- |
| 全部动态 | 不限制关注分组 |
| 第一个标签 | 第一个可用关注分组，标签名称使用该分组名称 |
| 第二个标签 | 第二个可用关注分组，标签名称使用该分组名称 |
| 其余分组 | 默认分组和其他未配置分组 |

如果账号只有一个可用关注分组，第一、第二个标签都会使用该分组；第二个标签的名称会在第一个分组名称后追加 `1`，例如“朋友”和“朋友1”。如果没有可用关注分组，则只显示“全部动态”和“其余分组”。首次保存后，配置按分组 ID 记录，分组改名不会丢失归属。

## 自定义组合

点击标签栏右侧的“配置”：

- 添加、删除、上移或下移标签；
- 修改标签名称；
- 为每个标签勾选多个关注分组；
- 修改“其余分组”的显示名称。

一个关注分组只能归属于一个自定义标签。默认分组固定归入“其余分组”。未被配置的分组和之后新建的分组会自动出现在“其余分组”中。

点击“更新成员”可以清除成员缓存并重新读取当前组合，适合在 B 站关注分组发生变化后使用。配置和成员缓存保存在当前浏览器的 Bilibili 本地存储中，不会修改 B 站的真实分组，也不会自动同步到其他浏览器。

## 性能说明

- 最多同时读取 3 个关注分组的成员列表。
- 成员列表缓存 5 分钟，并可在刷新页面后复用。
- 相同动态请求在 15 秒内短期复用，再分别应用当前标签的 UID 过滤。
- 首次读取包含大量成员的组合，或为了找到较早动态而自动补页时，仍可能需要等待。
- 保留上游实现的补页限制：每次最多继续读取约 10 页，连续多批没有匹配内容后停止。

## 来源与修改

本项目基于 [chengdidididi/bilibili-timeline-filter-tab](https://github.com/chengdidididi/bilibili-timeline-filter-tab) 的 MIT 许可脚本修改，保留其按关注分组获取 UID、拦截动态接口并过滤动态的核心思路。

本项目的主要修改由 [dust-iny](https://github.com/dust-iny) 完成：

- 重命名和整理用户脚本元数据；
- 添加 Bilibili Evolved 夜间模式和主题色适配；
- 添加多分组组合、自定义标签和“其余分组”；
- 添加成员缓存、并发加载、请求复用和过期加载取消；
- 增加配置界面、键盘可操作按钮和状态提示。

Bilibili Evolved 是相关页面主题适配的目标项目，不包含在本项目中。本脚本不修改 Evolved 设置。
